【赛题一】AI 赋能的「实时绘画」——风格化视频渲染系统

【赛题背景】

随着边缘计算与 AI 生成内容（AIGC）技术的发展，实时视频风格化已成为计算机视觉领域的热点应用。然而，传统方案依赖云端 GPU 或高端 AI 芯片，难以在低功耗、低成本边缘设备上实现低延迟、高吞吐量的视频流处理。

本赛题要求参赛队伍基于 RISC-V + FPGA 异构平台，设计一个轻量化神经网络硬件加速器。利用 FPGA 的并行流水线架构，将风格迁移网络（如简化版 CycleGAN、Fast Neural Style 或轻量化 CNN）完全或部分硬件化，实现对实时视频流的逐帧风格化处理。RISC-V 仅负责摄像头采集配置、视频流格式转换、UI 叠加等高层控制逻辑，从而构建一个低延迟、低功耗、高帧率的边缘 AI 视频处理系统。

【任务说明】

参赛队伍需设计并实现一个完整的实时视频风格化系统。系统通过 MIPI CSI-2 接口采集摄像头视频流，在 FPGA 中完成轻量化风格迁移网络的推理加速，将每一帧图像转换为指定艺术风格（如梵高、浮世绘、水墨画等），最终通过 HDMI 输出处理后的视频流。RISC-V 端需实现 UI 叠加功能，可同时显示原画与风格画对比视图。

【基础要求】

本部分考察学生对视频接口、神经网络硬件加速基础以及软硬协同设计能力的掌握。

1. MIPI 视频流采集与预处理

• 利用 Ti60 FPGA 的 MIPI 高速 I/O 资源，结合 MIPI D-PHY RX IP 和 CSI-2 RX Controller，完成 CSI-2 摄像头接入。（SC431HAI）。

• FPGA 端需实现 MIPI CSI-2 协议解析、RAW 转 RGB（如 debayer 算法）、图像缩放（Resize）至目标分辨率（最低要求：640×480 @ 30fps）。

• 实现双缓冲（Ping-Pong Buffer）机制，将预处理后的帧存入外部 DDR 存储器，确保数据流不丢帧。

2. 轻量化风格迁移网络的硬件加速器设计

• 选择一个轻量化风格迁移网络（参考：简化版 CycleGAN、Fast Neural Style、或自行设计的微型 CNN）。

• FPGA 端需为该网络设计一个硬件加速器，至少实现：

o 卷积层（Convolution）硬件化，支持 3×3 或 5×5 卷积核。

o 激活函数（如 ReLU）硬件化。

o 批归一化（Batch Normalization）或实例归一化（Instance Normalization）的硬件近似计算。

• 加速器需通过系统总线（如 AXI4）从 DDR 读取输入图像块，经流水线处理后写回结果帧。

3. HDMI 视频输出与软硬件协同

• 生成标准 HDMI 时序（最低要求 720p @ 60fps 或 1080p @ 30fps），从 DDR 读取风格化结果帧并输出至显示器。

• RISC-V 端需编写 C 语言驱动，完成：

o 摄像头初始化与寄存器配置。

o 风格迁移网络权重的加载与部署。

o 硬件加速器的任务调度（启动、等待完成、中断处理）。

• 实现原画 vs 风格画对比显示：屏幕左侧显示原始摄像头画面，右侧显示风格化后画面（或通过按键切换全屏模式）。

4. 基础 Demo 与性能验证

• 提供一个基础测试 Demo，展示实时风格化效果。

• 在屏幕上叠加显示当前帧率（FPS），要求稳定达到 15fps 以上（640×480 分辨率）。

【高阶挑战】

本部分考察对神经网络优化、多风格切换、高吞吐量流水线设计的深度理解。

1. 多风格实时切换

• 在 FPGA 内预置至少 2 种不同风格的网络权重（如梵高风格、浮世绘风格、水墨风格）。

• RISC-V 端可通过按键或串口指令，在不重启系统、不重新配置 FPGA 的前提下动态切换当前风格。

• 风格切换延迟应低于 100ms，且切换过程不丢帧。

2. 分辨率与帧率提升

• 将处理分辨率提升至 1280×720 @ 30fps 或更高。

• 需对硬件加速器进行流水线深度优化（如层间融合、行流式处理），减少对 DDR 的中间结果读写次数。

• 鼓励使用 DSP 块 实现高效的卷积计算（如脉动阵列、权重固定流）。

3. 超轻量化网络自设计

• 鼓励队伍自行设计或剪枝一个网络参数量小于 500KB 的超轻量化风格迁移网络。

• 需提交网络结构图、参数量统计表，并与标准网络（如简化版 CycleGAN）进行画质（PSNR/SSIM）与推理延迟的对比分析。

4. 创意交互展示

• 在基础对比视图之外，增加趣味交互功能。例如：

o 语音控制切换风格。

o 手势识别（如挥手）触发特殊滤镜效果。

o 将风格化画面实时推流至手机 APP（通过 WiFi 模块）。

• 鼓励录制 “抖音/B 站风格”展示短视频，作为附加材料提交。

【给参赛者的技术提示】

1. MIPI 内置 IP 优先：使用易灵思芯片内置的 MIPI D-PHY RX IP 和 CSI-2 RX Controller 进行 CSI-2 采集，可大幅降低外部电路复杂度。

2. 网络轻量化策略：建议优先考虑 U-Net 极小版、Fast Neural Style 的 1/4 通道版本，或直接使用 二值/三值神经网络（BNN/TNN） 简化乘法器需求。

3. 流水线设计关键：避免“整帧输入→整帧输出”的宏流水线，应采用行流水线（Line-based Pipeline），一行图像数据经卷积、归一化、激活后直接输出，极大减少 DDR 访问次数。

4. 画质与速度的平衡：不必追求与云端大模型完全一致的画质，体现“边缘实时性”比“极致画质”更重要。端侧 AI 的产业应用更关注流畅度与低延迟。

5. 展示效果最大化：建议对着彩色图案、人脸或风景画进行展示，风格化前后对比会更明显。若能做到挥手切换风格，现场互动效果极佳。
