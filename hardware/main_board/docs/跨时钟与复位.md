# 新整板工程的跨时钟约束

NPU、IPX、调度及 AXI 仲裁同处 `proc_clk`。DDR 通过原控制器的 `ASYN_AXI_CLK=1` FIFO 与 100MHz 核心连接，AXI 信号不直接跨域。没有对整个 proc 域设置宽泛的异步时钟组例外。

Framebuffer 的输入和输出侧各加入两拍复位释放同步器：所有域同时异步置复位，各域在自己的时钟上释放。proc 域采用三拍释放；摄像头模式切换沿用只停输入、排空在途 AXI 的方式，运行期间不随 KEY3 重置 DDR。

SDC 仅对以下明确的同步器首拍 D 设置 false path，次拍以及所有算术、AXI 数据路径仍受时钟约束：捕获/显示 FIFO 的 Gray 指针、帧开始/结束 Gray 计数、origin toggle、溢出/完整帧状态、显示 resync request/ack、首个最终帧有效标记。对应 RTL 两拍链标记 `async_reg`，工具 CDC 报告检查同步总线的偏斜。

origin_bin 和 origin_mode 是稳定的整帧快照，通过 toggle 握手采样。原值在相机帧开始锁存，toggle 经过两拍同步，正式捕获事件还延迟八个输入时钟。SDC 对其传输设置 6.6667ns 的最大延迟，保留物理延迟检查，而非放宽整个数据域。

异步复位例外限定到复位释放链的 SR 引脚。DDR watchdog 的复位例外限定到厂商已有 dout FIFO 的复位同步链；不对 DDR 数据接口或 calibration 控制数据添加例外。

检查最终时序和 CDC 报告时，应同时确认约束匹配实际端点。
