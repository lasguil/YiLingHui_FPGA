# Renderer 优化约束

本文记录本工程 NPU C bank 的固定几何接口合同。它用于限定合法模型/调度域内的优化，不代表 RTL 对任意软件构造的描述符都提供运行时验证。

## C bank 固定中心范围

`ngm_strip_sequencer` 为 T=120、四条带、固定 halo 5/4/3/2 生成中心范围。支持输入宽度为 2–480 个四像素组；条带起点为 0、120、240、360（末条带按输入宽度截断）。中心边界由 `clip_lo[h] = max(0, strip_start-h)` 与 `clip_hi[h] = min(width4, strip_start+120+h)` 生成。对应 Body0–Body3 的最大中心跨度分别为 130、128、126、124。


`SIM_ASSERT` 仅用于仿真；中心描述符跨度及容量检查在综合实现中不生成硬件保护。超出上述调度生成域的描述符（例如 Body1 的 `lo=0, hi=513`）不属于支持接口合同，硬件不保证拒绝它。不得把此行为描述成运行时范围防御。实际事务坐标、列序、ready/valid、行标签、ownership、X3/X4 preserve、同址读优先、回压和 AXI 错误处理属于独立保护，优化不得删除。

在上述合法域中，Body1–3 偶行中心地址的最大值分别为 `130+127=257`、`258+125=383`、`384+123=507`，均小于 512；奇行最大值分别为 765、891、1015，均位于高半区。因此合法 Body1–3 中心地址 bit9 等于行奇偶。Body0 奇行从 508 开始，会跨越 512；边缘字 1016/1017 也必须维持原映射。
