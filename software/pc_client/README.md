# 易灵绘电脑接收端

本目录提供 Windows 一键入口。网页保留现有 Android 端赛博朋克视觉资产的 PC 适配副本 `cyberpunk_ui/`；Android 原文件不修改。当前板2发送1280×720 MJPEG，软件直接组装JPEG并转发给浏览器，不在PC二次编码。

## 启动

双击 `start.bat`，或命令行运行：

```bat
start.bat
```

服务运行后自动打开 `http://127.0.0.1:8080/`。命令行保持开启，Ctrl+C退出。只检查本机而不启动：`start.bat --check`。不自动打开浏览器：`start.bat --no-browser`。网页8080被占用可改为 `start.bat --http-port 8081`；UDP端口必须与板2一致，不能随意改。

系统Python固定为项目规定的Python3.12，已安装的依赖为numpy和Pillow；启动器会检查依赖、必需文件和端口，并避免Efinity的PYTHONHOME串入。缺依赖时使用该解释器的 `-m pip install numpy pillow`，不自动创建环境。

## 无线连接

板1 HDMI输出接板2 HDMI输入，板2网口接VM300-L网桥；电脑连接该网桥的WiFi。当前固件板2IP为192.168.0.2，默认视频目的IP为192.168.0.3，因此电脑接收网卡须按现场网络配置到192.168.0.3/24，且局域网不能另有设备占用此地址。用网线直连也能使用同一软件，接收器不区分WiFi/以太网。

监听UDP5001视频、UDP5000控制及TCP8080网页。允许该Python程序通过相应Windows防火墙提示即可。软件不会替用户修改网卡、防火墙或WiFi模块，也不会关闭占端口的其他程序。若5000被其他应用占用，须释放它；板2控制回包固定发往5000，单改电脑端口并不可行。

## 同时连接板子与公网 API

当前 VM300-L 按独立局域网热点使用，本身不提供公网出口。电脑可用 Wi-Fi 接板子，再用有线网络或 USB 手机网络共享访问 Internet；板子网卡保留 `192.168.0.3/24` 的局域网地址，公网默认路由由另一条连接提供。不要给板子连接配置一个无法上网的默认网关；两条连接也应避免使用重叠的局域网网段。启动器只检查环境，不自动修改网卡或路由。

只有一张 Wi-Fi 网卡且没有其他上网连接时，当前独立热点拓扑不能同时访问公网 API；离线规则仍可用。也可将设备接入同一个有公网出口的局域网，但须先核实网桥模式、固定 IP 和视频目标地址，不能仅因控制 ACK 成功就认定视频已改向。

Android APK 则分别把板子 UDP 绑定到 Wi-Fi，把 API HTTPS 绑定到已验证的公网网络；必要时有界请求蜂窝网络。它不会替用户开启移动数据，也不把整个进程绑定到某一网络。

## 已有功能

- 实时MJPEG画面，帧率、码率、分辨率与连接状态。
- 适应窗口/原始像素、全屏、快照、视频流暂停/恢复。
- 鼠标或触控映射到板1的1920×1080画面，通过板2UART转发。
- 折叠控制区覆盖板1现有43种UI动作，包括模型、分辨率、视图、IPX颜色/饱和度/表等。
- 同页 Agent：离线规则（明确标为非 LLM）或可选 DeepSeek 计划，仅允许既有 `UI_ACTION` 和 `VIDEO_MODE`。计划先预览，执行时逐条等匹配 token 的 A 接收回执，失败即停止、不自动重发；A 接收不代表画面已更新。
- 诊断页：丢包、残帧、TX错误、采集序号与UART回执。接受命令与画面已应用明确区分。

PC 页面由 `net_web/streamd.py` 提供真实网络状态与 `/stream` 视频。诊断页中的接收配置为当前接收进程的只读启动配置；页面不会启动模拟源或伪造接收状态。手动控制和 Agent 计划复用 `live_agent.py` 白名单，并逐条等待板 A accepted；板端不可达时返回离线/超时状态。画面扫描仅在 Android 端有对应后端，PC 页面明确禁用该按钮。PC 页面源文件为 Android 现有页面和样式的隔离副本，修改视觉时应同步评审来源，不要直接改 Android APK 资产。

Agent 不具备绝对参数读回，因而只支持有界相对微调（每次 5%，最多 10 步），以及下一/上一模型、相对视图轮换、颜色方案 0–3、输入模式 0–3、菜单/暂停 toggle、表前后切换。绝对百分比目标会拒绝并说明原因；空间效果与 3D LUT 已移除。关闭/暂停之类不具备幂等 set 语义的操作会标为 toggle 或单次 UI 动作。

DeepSeek 需用户选择模式并填写 Key 与模型名；请求仅发到固定官方 HTTPS endpoint，不会上传视频帧。Key 由接收服务保存在当前进程内存，网页不会持久化；服务重启后需重新输入。离线模式不联网。未配置桥接或 B 控制离线时，Agent 执行不会发出动作。
