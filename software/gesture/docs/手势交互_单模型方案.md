## 1. 当前任务与类别（v4）

一个模型、一次单帧前向、一个分类头，固定输出 **握拳 / 一根手指朝上 / 拇指朝下 / 其他** 四类分数。

| ID | key | 类别 | 定义 | 数据目录 |
|---|---|---|---|---|
| 0 | `palm` | 手掌 | **五指张开**的手掌，掌心朝镜头 | `手掌/palm` |
| 1 | `finger_up` | 一根手指朝上 | 握拳，拇指或食指单独朝上伸出 | `其它/like`、`其它/one`、`其它/mute` |
| 2 | `thumb_down` | 拇指朝下 | 握拳，拇指朝下伸出 | `其它/dislike` |
| 3 | `other` | 其他 | 以上三者之外的一切 | 其余全部目录 + 外部负样本 |

类别 ID 与英文键固定在 [configs/g4net_v4.json](../configs/g4net_v4.json)，不依赖文件夹自动排序。
`one`（只竖食指）与 `mute`（食指竖在嘴前）与 `like`（拇指朝上）**手势结构相同**——都是握拳加一根手指朝上——因此合并为一类。

**三个正类都是「一个紧凑团块 + 少量突起」的剪影**，区别在突起的位置和数量：`palm` 是团块加 5 个张开的手指，`finger_up` 是团块加 1 个，`thumb_down` 是团块加 1 个朝下。负样本里明确包含**握拳**和**五指并拢举起的手**（见 §4）。

模型只输出单帧的四类分数。CPU 根据分数做稳定性判断、冷却、超时与事件去重；具体设备动作映射另行定义。
模型不输出方向、位移、动态动作、关键点或独立存在性位。

```text
整帧 RGB → 中央方形裁切 → 等比例缩放/填充 → G4Net → 四类分数 → CPU 时序与事件处理
```

输入 **RGB 192×192 方形**；部署时先取画面的中央方形，再交给同一个预处理函数。
网络结构、逐层计算量、预处理与量化约定见具体设计文档。

## 5. 判定规则

模型输出的四个分数不等于已校准的部署概率：训练时 batch 配额让"其他"只占 43.75%，而真实场景里"其他"是绝大多数帧。**接收规则由 CPU 侧决定**，配置在 [configs/g4net_v4_decision.json](../configs/g4net_v4_decision.json)，demo 与离线报告共用同一个函数（`src/decision.py`）。
