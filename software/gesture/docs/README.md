# 手势子系统文档索引

所有手势专项设计、训练和部署文档统一在本目录管理；数据目录保留就近的数据说明，第三方源码文档保留在原包内。

| 文档 | 用途 |
|---|---|
| [单模型方案](手势交互_单模型方案.md) | **★ 当前任务边界**：v4 的四个类别与输入、判定规则 |
| [G4Net 模型设计](G4Net_v1_模型设计.md) | 网络体（v1–v4 共用）、逐层预算、预处理、量化约定 |
| [GPOS v1 手部中心定位设计](GPOS_v1_手部中心定位设计.md) | **独立任务（非 g4net 的下一版）**：只输出手部中心热图、身体截断在 ds4、训练方法、NPU 改动清单 |
| [训练与评估流程](G4Net_训练与评估流程.md) | 已建成的管线、索引与划分、服务器启动方式、运行产物、判定规则与摄像头标定 |
| [四分类训练策略](四分类训练策略_采样与负样本.md) | 分层采样、外部负样本、CE/focal 对照、困难回放及误报评估 |
| [训练与部署指南](FPGA_低资源手势识别_设计与训练指南.md) | 从根目录 `docs/` 迁入的通用方法与验证流程 |
| [资产入口](../README.md) | 代码、模型和工具的状态 |

模型结构、类别顺序**与输入尺寸**以 [configs/g4net_v4.json](../configs/g4net_v4.json) 和 [src/model.py](../src/model.py) 为准，
**输入尺寸和类别表一样属于 checkpoint 的身份**：网络体与尺寸无关，拿错配置加载不会报错，只会静默按错误几何预处理，
所以加载权重必须按 checkpoint 里的 `model_id` 解析（`src/spec.py` 的 `INPUT_BY_MODEL`）。

项目背景见 [赛题原文摘录](../../../docs/赛题1_原文摘录.md)。
