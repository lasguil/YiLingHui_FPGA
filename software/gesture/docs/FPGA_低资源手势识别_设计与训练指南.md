# FPGA 低资源手势识别：训练与部署指南

> 更新：2026-10-15。当前模型（v4）固定为 **手掌 / 一根手指朝上 / 拇指朝下 / 其他** 四分类。
> 四类任务边界见 [单模型四分类方案](手势交互_单模型方案.md)，当前具体网络见 [G4Net v1 模型设计](G4Net_v1_模型设计.md)。
> 旧版检测器加分类器、方向类别与动作触发规则已撤出当前实现要求。

## 1. 任务与架构

模型负责单帧姿势分类；CPU 负责稳定性、时序、冷却、超时与事件去重，具体设备动作另行定义。

```text
摄像头原始图像 → 等比例缩放/填充 → 四分类 CNN
                                      ↓
                          握拳 / 一根手指朝上 / 拇指朝下 / 其他
                                      ↓
                              CPU 时序与事件逻辑
```

当前候选 G4Net 采用 Conv/DW/PW 骨干、GAP 和四类 FC 头，输入按版本固定（v1/v2 为 256×144，v3/v4 为方形 192×192，见 [单模型方案](手势交互_单模型方案.md) §3）。
手势子系统既有规划放在第二块 Ti60F225 板，图像来源与板间控制接口需在集成前明确；资源、时钟与吞吐以实际综合及板测为准。
手势是赛题创意交互扩展，不改变主系统实时风格迁移目标。

## 2. 数据与评估

现有 153,735 张图片的四类映射与数量见 [数据说明](../dataset/README.md)。

- 补齐图片路径、类别和来源元数据；公开数据按图片分层随机划分并固定 seed，自采摄像头数据按录制场次划分。现有分类镜像无法恢复到人物粒度，且本版不做该项恢复，公开数据指标偏乐观，只作开发期相对比较，验收以摄像头独立数据为准（见[训练策略](四分类训练策略_采样与负样本.md) §2）。
- 其他类占 HaGRID 部分的 78%，按 [四分类训练策略](四分类训练策略_采样与负样本.md) 做类别/来源分层采样，先 CE、再同条件 focal 对照；不能只用总准确率判断效果。
- 报告四类混淆矩阵及每类 precision/recall，重点检查三个拳头类之间的混淆。
- 增加目标摄像头的独立测试数据，覆盖不同距离、光照、肤色、遮挡、复杂背景和多手场景。
- 单列无手背景与其他易混负样本；no_gesture 不能直接等同于无手。
- 模型先验收单帧四分类；CPU 逻辑接入后再用连续视频评价误触发和响应延迟。

## 3. 训练与量化

1. 先训练浮点四分类基线，固定并保存类别顺序、输入尺寸、灰度/RGB、缩放填充和归一化参数。
2. 基于真实测试表现调整网络与输入尺寸；计算量预算不代表识别效果。
3. 基线稳定后做 INT8 PTQ/QAT；量化方案与硬件精确数值行为保持一致。
4. 导出逐层 shape、MAC、权重字节数、特征字节数及 golden tensors。

量化须明确 signed/unsigned、zero-point、逐通道权重 scale、bias scale、舍入、饱和和 requantize 行为。
BN 在导出前折叠进卷积。逐层验证输入、累加和输出，定位误差后再调整位宽或 scale。

## 4. 硬件开发与验证

候选算子集为 Conv3×3、DWConv3×3、PWConv1×1、ReLU6、requantize、GAP、FC。
最终按训练模型确定算子与调度，不引入历史检测器的 anchor、NMS 或 ROI 通路。

1. 实现 bit-exact INT8 reference，保存逐层对拍数据。
2. 按层统计 cycles、存储及访存预算，再确定 DSP 配置。
3. 验证单层算子、缓冲和 DMA，随后验证完整四分类推理。
4. 综合与布局布线检查功能逻辑、routing、DSP、RAM 和时序，最后板测吞吐与稳定性。

DSP 的双 INT8 吞吐、工作频率与利用率均须验证，不能直接将理论峰值当成实现性能。
DMA、缩放、跨时钟域、FIFO 和控制逻辑也需计入完整子系统资源。
